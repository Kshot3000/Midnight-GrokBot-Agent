Agent Escrow — local stub

Walk the milestone escrow state machine in the browser. This page does not talk to Lace, a proof server, or the chain. The real Compact skeleton lives under contracts/agent-escrow and uses witness-derived role commitments (MPS-0029 — never ownPublicKey() alone).

Stub only — no on-chain deploy. Compile with Compact ~0.31.1 before any real circuit work. Auth on Midnight must use witness + persistentHash, not ownPublicKey() for authorization (MPS-0029).
Role

Client

Funds, starts, disputes, settles, cancels. Always an approver.

Role

Agent

Submits proof hashes. Never approves or releases own work.

Role

Approver

Releases or rejects after a proof exists. Registered at init.
