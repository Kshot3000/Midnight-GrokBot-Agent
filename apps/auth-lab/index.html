The rule in one screen

Safe uses of ownPublicKey() are token routing after a real auth gate — never the gate itself.

Unsafe

Auth via ownPublicKey()

Prover picks any 32-byte value. Assertions that compare it to a stored owner are theater.

  • assert(ownPublicKey() == admin)
  • Blacklists keyed only by ownPublicKey()
  • Role maps filled from ownPublicKey() at register
Safe

Witness-derived identity

Caller proves knowledge of a secret. Derive a public commitment in-circuit (bboard / zkloan pattern).

  • witness localSecretKey(): Bytes<32>
  • publicKey(sk) / persistentHash with domain sep
  • ownPublicKey() only to route shielded coins

Public claim rail

Anyone can assert “I am Alice” by stuffing Alice’s pk into the witness.

0% forge pressure

Secret-bound rail

Without Alice’s secret, Mallory’s derived pk never matches owner.

100% integrity (until safe deploy)

    ✗ Forgeable
    

    export ledger owner: ZswapCoinPublicKey;

constructor() {
  owner = ownPublicKey(); // anyone can later claim this
}

export circuit adminOnly(): [] {
  assert(ownPublicKey() == owner, "not owner"); // bypassable
}
    
        
    
        
    
          
    ✓ Witness-derived (bboard-style)
    

    witness localSecretKey(): Bytes<32>;

export ledger owner: Bytes<32>;

constructor() {
  owner = publicKey(localSecretKey());
}

export circuit adminOnly(): [] {
  assert(
    disclose(publicKey(localSecretKey()) == owner),
    "not owner"
  );
}
