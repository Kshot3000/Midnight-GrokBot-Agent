What is Midnight?

Midnight is a fourth-generation blockchain designed for programmable privacy: developers write smart contracts in Compact, which compiles to TypeScript/JavaScript bindings and zero-knowledge circuits. Public ledger state stays on-chain; private state can remain local to the client, with selective disclosure when required.

  • Hybrid UTXO + account-style contract updates in atomic steps
  • Dual-state ledger: public on-chain state ↔ local private state via ZK proofs
  • Built for real-world regulated workflows without exposing all data by default

Source of truth: midnight.network · docs.midnight.network

NIGHT & DUST (high-level)

NIGHT

Native unshielded utility / governance token. Registered NIGHT holdings generate the DUST resource used for fees. Testnets use tNIGHT from the faucet.

DUST

Shielded, non-transferable network resource consumed to pay transaction fees. Regenerates over time from registered NIGHT (test: tDUST).

Details: NIGHT overview · Acquire tokens / faucet guide · Glossary

Start building

  1. Install Compact + proof server from the official installation guide (pin versions from the compatibility matrix — see our research pins).
  2. Install Lace, select the Midnight network (e.g. Preprod for test work), and fund with faucet tNIGHT → generate tDUST.
  3. Explore contracts/hello-midnight/hello.compact in this repo, then follow an official tutorial such as the privacy-preserving leaderboard DApp.
  4. Open the live lab on GitHub Pages or serve locally: cd apps/midnight-lab-site && python3 -m http.server 5173
  5. Try the Lace connect demo: Pages /lace/ or npm run dev:lace-demo → http://localhost:5174
  6. Walk the Agent Escrow stub: Pages /escrow/ or cd apps/agent-escrow-stub && python3 -m http.server 5175
  7. Auth Lab — Pages /auth/ or cd apps/auth-lab && python3 -m http.server 5176
  8. Shield Board (flagship) — Pages /board/ or cd apps/shield-board && python3 -m http.server 5177
