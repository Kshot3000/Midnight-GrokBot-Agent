Night Market Studio

World-class educational marketplace for Midnight’s dual-state model: publish a sealed listing (public title + commitment hash), collect private bids whose amounts stay in the vault, then prove a bid meets the reserve without revealing either number — or award & selectively disclose when the stall closes.     Anti-pattern vs safe pattern

    Teaching sketches — not deployable Compact. Always verify against official docs.

    ✗ Anti-pattern — clear reserve on-chain
    // BAD: public ledger sees the floor
ledger {
  reserve: Uint<64>;  // observers learn the floor
  title: Bytes<64>;
}
    ✓ Safer sketch — commit + witness
    // BETTER (sketch): public commitment only
ledger {
  listingCommit: Bytes<32>;
  title: Bytes<64>;
}
witness reserveAda: Uint<64>;
// prove bid ≥ reserve without publishing either

    These snippets are educational illustrations. Official Compact syntax, circuits, and Zswap commitments may differ — check Midnight docs before shipping.
