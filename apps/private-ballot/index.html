      Anti-pattern vs safe pattern

      Teaching sketches — not deployable Compact. Always verify against official docs.

      ✗ Anti-pattern — clear votes on-chain
      // BAD: public ledger sees every choice
ledger {
  voter: Bytes<32>;   // identity leaked
  choice: Uint<8>;    // vote leaked
}
      ✓ Safer sketch — commit + nullifier
      // BETTER (sketch): public commit + nullifier
ledger {
  ballotCommit: Bytes<32>;
  nullifier: Bytes<32>;  // unique, no identity
  tallies: Vector<Uint<64>>;
}
witness choice: Uint<8>;
witness voterSecret: Bytes<32>;
// prove eligible + one-vote without publishing who

      These snippets are educational illustrations. Official Compact syntax, circuits, and Zswap commitments may differ — check Midnight docs before shipping.
