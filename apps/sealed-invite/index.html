    Anti-pattern vs safe pattern

    Teaching sketches — not deployable Compact. Always verify against official docs.

    ✗ Anti-pattern — clear guest list on-chain
    // BAD: public ledger sees every name
ledger {
  guests: List<Bytes<64>>;  // observers dox the party
  capacity: Uint<32>;
}
    ✓ Safer sketch — commit + witness
    // BETTER (sketch): public commitment only
ledger {
  inviteCommit: Bytes<32>;
  rsvpCommits: List<Bytes<32>>;
}
witness capacity: Uint<32>;
witness guestName: Bytes<64>;
// prove seatsRemain without publishing names

    These snippets are educational illustrations. Official Compact syntax, circuits, and Zswap commitments may differ — check Midnight docs before shipping.
