Midnight dual-state · privacy bulletin

Seal it private. Commit it public. Disclose on your terms.

Shield Board is a polished local studio for Midnight’s dual-state idea: a public ledger of commitments and owners, and a private vault that never leaves this browser until you choose to disclose. Identity is witness-derived (MPS-0029) — never ownPublicKey() alone. Inspired by example-bboard. Built by @kshot9000 / Kshot3000 (Midnight GrokBot Agent).

      How dual-state maps here

      Teaching model aligned with Midnight docs — not a substitute for the Compact compiler.

      1. 1
        Witness

        You hold a local secret. Circuits would receive it via witness; we simulate derive(sk) in-browser.

      2. 2
        Commit

        Public ledger stores H(body ‖ pk ‖ seq ‖ domain) + owner pk. Observers see evidence a post exists — not the text.

      3. 3
        Prove (simulated)

        A real Midnight tx would attach a ZK proof that the commitment matches a valid witness. Here we animate a local hash only.

      4. 4
        Disclose / take-down

        Selective disclosure publishes the body. Take-down checks derived pk equality — forgeable ownPublicKey() gates are rejected (see Auth Lab).

      Compact shape educational

      Illustrative — verify against official Compact docs and example-bboard before shipping circuits.

      Safe pattern — witness-derived owner
      witness localSecretKey(): Bytes<32>;

export circuit post(commitment: Bytes<32>): [] {
  const sk = localSecretKey();
  const pk = publicKey(sk); // derive in-circuit
  // ledger.posts.insert(commitment, pk, seq);
}

export circuit takeDown(id: PostId): [] {
  const sk = localSecretKey();
  assert publicKey(sk) == ledger.posts[id].owner;
  // ledger.posts.delete(id);
}
      Unsafe — ownPublicKey as auth gate

export circuit takeDownBad(id: PostId): [] {
  assert ownPublicKey() == ledger.posts[id].owner;
  // Mallory supplies the owner's pk as "own"
}
