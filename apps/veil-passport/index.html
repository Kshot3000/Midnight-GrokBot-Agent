    Anti-pattern vs safe pattern

    Teaching sketches — not deployable Compact. Always verify against official docs.

    ✗ Anti-pattern — publish all claims
    // BAD: verifier sees every attribute
ledger {
  holder: Bytes<32>;
  age: Uint<8>;       // exact age leaked
  role: Bytes<16>;    // role leaked
  membership: Bytes<8>;
}
    ✓ Safer sketch — commit + selective + predicate
    // BETTER (sketch): public commit only
ledger {
  credCommit: Bytes<32>;
  issuerSig: Bytes<64>;
  revokeNull: Bytes<32>; // optional
}
witness age: Uint<8>;
witness salt: Bytes<32>;
// prove age >= 18 without publishing age
// selectively open role only when needed

    These snippets are educational illustrations. Official Compact syntax, circuits, and Zswap commitments may differ — check Midnight docs before shipping.
