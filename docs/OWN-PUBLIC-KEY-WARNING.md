# ownPublicKey() is not a caller authenticator

**Upstream issue:** [midnightntwrk/midnight-docs#902](https://github.com/midnightntwrk/midnight-docs/issues/902)  
**Official docs:** [Smart contract security](https://docs.midnight.network/compact/smart-contract-security) · [Security and best practices](https://docs.midnight.network/guides/security-best-practices)

## Summary

`ownPublicKey()` returns the Zswap coin public key of the user executing the circuit. It is implemented as a witness. The prover supplies the value; the protocol does not cross-check it against the wallet that signs the transaction.

Therefore:

- `assert(ownPublicKey().bytes == someStoredKey)` compares two prover-controlled values and can be bypassed.
- Never use `ownPublicKey()` to decide *who may call* a circuit.
- Use it only *after* the caller has been authenticated by another means (for example to route a shielded token to the proven caller).

## Correct pattern (Compact ~0.31.1 / language ~0.23)

Derive a public identity from a secret the caller must know, store the hash, and assert the caller can reproduce it:

```compact
witness secretKey(): Bytes<32>;
export pure circuit deriveOwner(sk: Bytes<32>): Bytes<32> {
  persistentHash<Vector<2, Bytes<32>>>([pad(32, "lab:ownpk:owner:v1"), sk]);
}
export ledger owner: Bytes<32>;
constructor() {
  owner = disclose(deriveOwner(secretKey()));
}
export circuit setValue(v: Uint<64>): [] {
  assert(deriveOwner(secretKey()) == owner, "unauthorized");
}
```

See `contracts/hello-midnight/own-public-key-warning.compact` for the full invariant.
