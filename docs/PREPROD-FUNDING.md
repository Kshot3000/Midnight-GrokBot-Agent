## Why two tokens

Every Midnight tx consumes **DUST**. DUST is generated by holding **NIGHT** that you have **registered** for DUST generation. On Preprod both are free test tokens (`tNIGHT` / `tDUST`).

## Step 1 — Unshielded address

Faucet accepts **only** unshielded addresses starting with `mn_addr_preprod`.  
Rejects shielded (`mn_shield-addr_preprod`) and DUST (`mn_dust_preprod`) addresses.

Generate a throwaway lab wallet (secrets stay gitignored):

```bash
export PATH="$HOME/.local/share/fnm:$PATH"
eval "$(fnm env)" && fnm use 22
npm run stub:wallet-gen
# → prints public mn_addr_preprod…
# → writes mnemonic/seed under .secrets/ and /workspace/secrets/midnight-preprod/
```

Or use Lace Midnight wallet → copy the unshielded address.

## Step 2 — Request tNIGHT (faucet)

1. Open https://midnight-tmnight-preprod.nethermind.dev/ (or the alt host).
2. Paste `mn_addr_preprod…` (no spaces).
3. Complete the **captcha** → Request tokens.
4. Expect **~1,000 tNIGHT** within a couple of minutes (rate limited).

### Automation note (lab)

The faucet UI posts to `POST {faucet}/drips` with body `{ recipientAddress, amount }` and header `X-Captcha-Token`.  
Without a captcha token, `npm run stub:faucet-attempt` **fails clearly** — that is expected. Use the browser.

## Step 3 — Register for tDUST

tNIGHT alone is not enough. Submit fails with `Wallet.InsufficientFunds` until spendable **tDUST** exists.

**Lace:** open Midnight wallet → **Generate tDUST** (label may vary) and wait until tDUST balance is non-zero.

**Programmatic:** follow https://docs.midnight.network/guides/generating-dust-programmatically  
(`registerNightUtxosForDustGeneration` after wallet sync; optional `midnight-dust-generator` helper).

Initial DUST accrual can take **1–2 minutes** after registration confirms.

## Step 4 — Proof server (local)

```bash
# Reuse existing healthy container if present
curl -sS http://127.0.0.1:6300/health
# or start:
npm run proof-server:podman
```

Proof server sees witness data in the clear — keep it local even on Preprod.

## Step 5 — Env + deploy gate

```bash
cp .env.preprod.example .env.preprod
# paste MIDNIGHT_WALLET_MNEMONIC from .secrets/preprod-throwaway.env
npm run stub:require-wallet   # exits 2 if missing — intentional
npm run stub:providers        # wiring + probes (NOT a deploy)
npm run stub:deploy-preprod   # refuses submit without keys / allow flag / tDUST
```

**Do not claim Preprod deploy success** until a tx is confirmed (explorer / `deployTxData.public.contractAddress`).
