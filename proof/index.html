What a Midnight-style proof is really saying

Observers see public outputs + a proof. Witnesses stay local. The circuit constrains what those witnesses are allowed to imply.

Private witnesses

Never leave the client in the dual-state model. Teaching stand-in: values you type below.

  • Secret amounts, salts, identities
  • Opening notes for commitments
  • Intermediate gate wires

Public outputs

What the simulated “ledger” / verifier is allowed to see.

  • Commitment hashes
  • Threshold / range flags
  • Selective disclose payloads (optional)

    Anti-pattern vs safe pattern

    Teaching sketches — not deployable Compact. Always verify against official docs.

    ✗ Anti-pattern — clear witnesses on-chain
    // BAD: public ledger sees the secret
ledger {
  amount: Uint<64>;   // observers learn the tip
  salt: Bytes<32>;
}
    ✓ Safer sketch — commit + prove
    // BETTER (sketch): public commitment only
ledger {
  commit: Bytes<32>;
  thresholdMet: Boolean;
}
witness amount: Uint<64>;
witness salt: Bytes<32>;
// prove amount >= T without publishing amount

    These snippets are educational illustrations. Official Compact syntax, circuits, and Zswap commitments may differ — check Midnight docs before shipping.
